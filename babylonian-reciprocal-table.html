Only regular numbers — numbers built purely from the primes 2, 3, and 5 — appear as p. Those are the only ones whose partner terminates cleanly in base 60, exactly like the reciprocal tables Babylonian scribes carved into clay; a number like 7 or 11 would produce an endlessly repeating fraction. A comma separates every sexagesimal digit, whole part and fraction alike, the way the original tables write it: 7, 30 means 7 and 30/60 (7.5); 2, 13, 20 means 2 + 13/60 + 20/3600. The whole/fraction boundary isn't marked, so where a number "starts" is a matter of context — just as it was on the original tablets.

In Cuneiform mode each digit (0–59) is drawn the way a scribe would impress it: a corner wedge per ten, a thin wedge per one, grouped into a little clay block per sexagesimal place. The same thin line divides every digit group, whole part and fraction alike — nothing marks where the fraction begins, just like the commas above. There was no true zero in Old Babylonian numerals — scribes just left a gap — so a plain groove mark stands in for it here.
